# Support Agent

Ein First-Level-Support-System auf Basis des OpenAI Agents SDK.

## Ziel
Dieses Projekt dient dem Aufbau eines lokalen und später webbasierten Support-Agenten mit:
- Python
- FastAPI
- OpenAI Agents SDK
- eigener Tool-Integration

## Projektstruktur
- `app/` Anwendungscode
- `tests/` Tests
- `scripts/` Hilfsskripte
- `data/` lokale Test- und Wissensdaten

## Lokale Entwicklung
1. Python 3.11 verwenden
2. Virtuelle Umgebung erstellen
3. Abhängigkeiten installieren
4. `.env` auf Basis von `.env.example` anlegen
